One sentence, 155 characters, written to convince a friend who has never coded to let an AI agent build their first app idea on make.fun.

## The entry

> Just describe your idea in plain words and let an AI agent on make.fun build it into a real app you can tap — no code, no setup, nothing to lose by trying.

## How to run

Requires Node 22 or later. The program writes the pitch to `/output/entry.txt`:

```sh
node main.ts
cat /output/entry.txt
```

The output is a single sentence of 155 characters, inside the gate of 1–240 characters.
